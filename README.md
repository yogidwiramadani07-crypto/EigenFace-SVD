Project deteksi wajah menggunakan metode EigenFace dan Singular Value Decomposition (SVD) menggunakan Python.

## Features
- Mean Face
- SVD
- EigenFace
- Face Recognition

## Library

- Matplotlib

# Hubungan dengan SVD
```
Pada program Python, proses utama menggunakan rumus:
A = U \Sigma V^T
Rumus tersebut digunakan untuk:

Memecah matriks wajah
Mencari eigenvector
Menghasilkan EigenFace

Dimana:

A = matriks wajah
U = matriks ortogonal
Σ = singular values
Vᵀ = eigenvector / eigenface
```
